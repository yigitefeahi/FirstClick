# Onboarding and activation (aha moment)

When the onboarding risk score is high, setup friction is usually present. This document is FirstClick’s onboarding evaluation standard.

## First success (time-to-value)
- Ideal: signup → first value ≤ 5 minutes.
- An empty state should give a task: “Create your first board”, “Issue your first invoice”.
- An empty screen with no guidance = high onboarding risk.
- A progress checklist (3–5 steps) motivates the busy-professional.
- Trial without a credit card is critical for price-sensitive and student personas.

## Setup friction
- More required fields ↑ → drop-off ↑.
- Fast OAuth signup is good; but if only Google is allowed, some users leave.
- If Slack/Jira integration is mandatory on day one, aha is delayed — keep it optional.
- If you promise “one click”, steps should be 1–3; otherwise you get a citable contradiction.

## Activation metrics (product language)
- The activation event must be clearly defined: “first sprint created”, “first invite sent”.
- Invite loop: if a single-user product promises team value, users feel stranded alone.
- Templates / sample data: accelerate the first-timer.

## Persona × onboarding
- non-technical: step-by-step wizard, tooltips, video.
- busy-professional: skip tour + fast path.
- skeptical: explain “why do you need this permission?”.
- first-timer: jargon glossary, sample scenario.

## Session timeline mapping
- Getting stuck in setup = friction high.
- Landing OK but getting lost in setup is a classic pattern.
