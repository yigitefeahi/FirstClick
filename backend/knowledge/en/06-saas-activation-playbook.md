# SaaS Activation Playbook

These rules are prioritized when the sector package SaaS is selected.

## PLG (product-led growth) checklist
- Self-serve signup
- Fast aha moment
- Invite / share loop
- Upgrade moment (limit hit) should be fair
- In-app checklist

## Example activation events
- First project created
- First integration connected
- First team invite
- First report exported

## Early churn signals
- Setup left incomplete
- No invite sent
- 7 days of inactivity

## Points to analyze
If the pitch says "for teams", is single-user onboarding insufficient?

## Extended expert notes

### Depth Note Landing-1
The FirstClick analyst reads hero, value proposition, and CTA signals together in the Landing area. If there is a hero promise in the product corpus, a contradiction with the UI/value proposition is sought; if not, the [kb] general rule is applied. In persona feedback, CTA friction is written to the timeline. Concrete suggestion: reduce the hero text to a single sentence, provide visual proof for the value proposition, add micro-assurance for the CTA. Score impact: clarity and adoption are sensitive to landing quality; onboardingRisk increases if there is a lack of value proposition.
