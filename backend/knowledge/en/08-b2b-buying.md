# B2B Purchasing and Enterprise Objections

In the B2B package, busy-professional + skeptical personas work together.

## Buying Committee
- Champion, economic buyer, security, end user.
- A single persona is not enough; toughQuestions should include security and ROI.

## Sales Friction
- Sales only via demo → Startups expecting PLG are missed.
- If "Book a demo" is the only way, self-serve score drops.

## ROI Language
- Time savings, error reduction, cost.
- ROI without evidence angers the skeptical persona.

## Compliance
- SSO, audit log, and role-based access are expected in B2B.
