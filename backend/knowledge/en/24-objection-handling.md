# Objection Handling

## Common Objections
1. Too expensive
2. We already use X
3. Hard to learn
4. Data security
5. My team won't want it

For each objection, there should be a landing FAQ or in-app answer. If not, it falls under toughQuestions.

## Extended Expert Notes

The analyst reads CTA signals together. If there is a hero promise in the product corpus, a contradiction is sought between the UI/value proposition; if not, the [kb] general rule is applied. In persona reactions, CTA friction is recorded on the timeline. Concrete suggestion: reduce the hero copy to a single sentence, provide visual proof for the value proposition, add micro-assurance for the CTA. Score impact: clarity and adoption are sensitive to landing quality; onboardingRisk increases if the value proposition is lacking.
